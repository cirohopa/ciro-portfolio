## 💻 Informações Técnicas do Portfólio

Este portfólio foi construído do zero focando em alto desempenho, acessibilidade, código limpo e uma experiência de usuário moderna e agradável.

### ⚙️ Tecnologias Utilizadas
- **HTML5 Semântico:** Estrutura clara, acessível e otimizada para SEO.
- **CSS3 Puro (Vanilla CSS):**
  - Sistema de temas via **CSS Variables** (`--bg-main`, `--surface`, `--cyan`, `--sapphire`).
  - Layouts dinâmicos utilizando **Flexbox** e **CSS Grid**.
  - Estilização moderna com **Glassmorphism**, efeitos de *glow* e micro-interações.
  - Tipografia otimizada importada via Google Fonts (`Kanit` para títulos e `Inter` para o corpo do texto).
- **JavaScript (ES6+ Vanilla):**
  - **Alternância de Tema (Dark/Light Mode):** Persistência no `localStorage` do navegador e leitura do tema atual via atributo `data-theme`.
  - **Navegação Suave (Smooth Scroll):** Rolagem fluida para seções ao clicar nos links do menu.
- **Lucide Icons:** Ícones modernos e vetoriais integrados dinamicamente via CDN.

### 📂 Estrutura do Repositório
```
portfolio_ciro/
├── index.html   # Estrutura HTML semântica e conteúdo do portfólio
├── style.css    # Design System, variáveis de tema (dark/light) e responsividade
├── script.js    # Alternância de temas (dark/light mode) e scroll suave
└── README.md    # Documentação do projeto e informações do perfil
```
